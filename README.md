# 大A爆破实验室

这是“大A爆破实验室”的第一版静态原型，重点不是展示复杂指标，而是把“阶段、边际变化、资金确认”放在同一个决策界面里。

## 在线地址

- 本地完整版（支持启动采集器）：`http://127.0.0.1:8771/`
- GitHub Pages（只读页面）：`https://nancybhc.github.io/a-share-blast-lab/`
- GitHub 仓库：`https://github.com/nancybhc/a-share-blast-lab`

## 打开方式

如需使用网页上的“启动全市场采集”按钮，双击 `启动网站.cmd`。它会启动本地控制服务并自动打开：

```text
http://127.0.0.1:8771/
```

只查看静态页面时，也可以直接双击 `index.html`，但此时浏览器无法执行本地采集器，按钮会显示“需用启动网站.cmd”。

也可手动启动网页服务：

```powershell
python "server.py" --port 8771
```

## 网页采集按钮

全市场资金面板右上角有“启动全市场采集”按钮：

- 点击后由本地服务启动采集子进程
- 休市时显示“等待开盘”
- 交易时段显示“采集中”
- 再次点击即可停止
- 页面每 60 秒同步采集状态，并在有新快照时自动刷新盘中数据
- 运行日志位于 `data/collector.log`

## 数据入口

当前数据集中维护在 `app.js` 顶部的 `marketData` 对象中。正式版可将该对象替换为由多空阶段流水线自动生成的 `market.json`。

资金数据位于 `data/group_fund_flows_2026-10-23.json`，页面同时读取同名 `.js` 文件，保证直接双击页面时也能显示数据。

资金口径为新浪财经历史资金流接口中的 `r0_net`（主力净流入），按多空阶段的 17 个自定义分组成分股逐只汇总。2026-10-23 快照覆盖 891 只去重标的，股票数据覆盖率为 100%。

个股级明细在 `data/stock_fund_flows_2026-10-23.csv`。数据生成脚本为 `data/fetch_group_fund_flows.py`。

2026-10-23 半导体芯片实际结果：

- 当日主力净流入：`+44.86 亿`
- 较 10-22 增加：`+33.07 亿`
- 近 5 日累计：`+116.06 亿`

此前口述的 `-155亿 → +75亿` 更接近东方财富“国产芯片”板块的日级变化（-107.75亿 → +79.92亿）或盘中极值附近；它属于板块级口径，不能与上述自定义分组汇总直接混算。

## 分钟级资金采集

东方财富分钟级资金接口仅提供当前交易日的分时序列，收盘后不会提供历史回补。因此盘中最大流出点必须在交易时段自行采样。

双击 `启动盘中资金采集.cmd`，采集器会在 09:20-11:35、12:55-15:05 每 30 秒抓取以下板块：

- `BK0917` 半导体概念
- `BK0891` 国产芯片
- `BK1036` 半导体

输出位于 `data/intraday/<交易日>_<板块代码>.json`，会自动计算：

- 盘中主力净流出最低点及时间
- 盘中主力净流入最高点及时间
- 最新累计主力净流入
- 最低点到最高点的资金回补幅度

也可手动执行一次：

```powershell
python "data\capture_intraday_fund_flow.py" --ignore-session
```

或回填日级板块资金：

```powershell
python "data\capture_intraday_fund_flow.py" --backfill-daily --date 2026-10-23
```

## 全市场资金采集

全市场资金数据来自东方财富 `clist` 接口的 `f62` 主力净流入字段。

2026-10-23 收盘快照：

- 行业板块：496 个
- 概念板块：516 个
- A 股标的：5925 只
- 有有效资金流数据：5572 只
- 有效个股主力净流入合计：+8.35 亿元
- 流入 2183 只、流出 3352 只

全量日线和个股明细位于：

- `data/full_market/full_market_daily_2026-10-23.csv`
- `data/full_market/full_market_daily_2026-10-23.json`

双击 `启动全市场资金采集.cmd` 后：

- 行业和概念板块默认每 30 秒采样一次
- 全体个股默认每 300 秒采样一次
- 每个板块记录 `最低流出 / 发生时间 / 最高流入 / 发生时间 / 收盘值 / 回补幅度`
- 全市场个股合计记录同样的最低、最高、收盘和回补统计
- 汇总 CSV 位于 `data/full_market/full_market_intraday_summary_<交易日>.csv`

手动启动：

```powershell
python "data\capture_full_market_fund_flow.py" --watch --interval 30 --stock-interval 300
```

抓取一次当前/收盘快照：

```powershell
python "data\capture_full_market_fund_flow.py" --snapshot
```

注意：公共分钟资金接口不保留已收盘交易日的完整历史分时。因此 2026-10-23 的盘中最低点只能显示为“未采样”，从下一次交易时段开始由本地采集器完整记录。
